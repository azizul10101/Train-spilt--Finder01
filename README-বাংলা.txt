Train Split Finder v3 — APK বানানোর নিয়ম
=========================================
1. github.com এ অ্যাকাউন্ট খুলুন → New repository (Private রাখাই ভালো)।
2. এই ফোল্ডারের সব ফাইল (লুকানো .github ফোল্ডার সহ) Upload করুন।
3. Actions ট্যাব → "Build APK" চলবে (৩-৫ মিনিট)।
4. শেষ হলে repository এর ডান পাশে "Releases" এ যান → TrainSplitFinder.apk চাপ দিয়ে ফোনে সরাসরি নামান।
5. ইনস্টল করুন। পরের বার আপডেট করলে পুরোনোটা মুছতে হবে না (একই key দিয়ে সাইন করা)।
